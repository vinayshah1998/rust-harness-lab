1. Ask before acting

checked_path answers one question: is this request valid? There's a second question it can't answer: is it allowed? A perfectly valid edit to src/main.rs can still be one you don't want, and only the person running the agent can decide that. Validation is about the request. Permission is about you.

The second rule matters just as much: permission must come from you, never from the conversation. Claude reads files, and a file can say “the user approves all edits.” If text could grant permission, any file could grant it. So the approval decision lives in the harness, wired to your keyboard, and nothing Claude reads or writes can reach it.

In this chapter, reading tools keep running freely, and edit_file asks you first.

Specification

  • ToolDefinition gets a field needs_approval: bool, marked #[serde(skip)] because Claude never needs to see it. It's false for read_file and list_files, and true for edit_file.
  • Agent gets a field approve: Box<dyn FnMut(&str, &Value) -> bool>, passed as a third argument to Agent::new. It receives the tool name and input and returns whether the call may run.
  • execute_tool takes &mut self. After finding the tool and before running it, if the tool needs approval, it calls approve. If that returns false, it returns an error result with the text the user did not allow this {name} call and doesn't run the tool.
  • main passes Box::new(ask_user). ask_user prints Allow edit_file({...})? [y/N], reads a line, and returns true only for y or Y. Anything else, including an empty line or end of input, means no.
Warm-up A closure stored in a struct

This Agent stores its approver exactly the way ours will. The closure counts how often it's asked. Will it compile?

struct Agent {
    approve: Box<dyn FnMut(&str) -> bool>,
}

fn main() {
    let mut count = 0;
    let mut agent = Agent {
        approve: Box::new(|name| {
            count += 1;
            name == "read_file"
        }),
    };
    println!("{}", (agent.approve)("edit_file"));
    drop(agent);
    println!("asked {count} times");
}

Run it in the Rust Playground, but write down your prediction first.

Show the answer

No: error[E0597]: `count` does not live long enough. The compiler adds a note that explains everything: Box<dyn FnMut(&str) -> bool> in a struct field “actually means” Box<dyn FnMut(&str) -> bool + 'static>.

A boxed closure in a field can outlive the function that created it, so by default Rust requires it to borrow nothing that could go away. That's what 'static means here. This closure borrows the local variable count, so it doesn't qualify.

Now try writing move |name| instead. It compiles, and prints false and then asked 0 times. move gave the closure its own copy of count, because integers are Copy, so the outer count never changes. The compiler even warns value captured by `count` is never read. That's why our approvers either capture nothing, like the tests' closures, or are plain functions, like ask_user. Sharing a counter between a closure and its creator takes shared ownership, Rc<Cell<usize>>, which the Book covers in chapter 15.

Read: §13.1 Capturing references or moving ownership · §10.3 The static lifetime · §15.4 Rc

Rust concept · behavior in a field, and borrowing two fields at once

Box<dyn FnMut(&str, &Value) -> bool> is “any callable with this shape, on the heap.” We use FnMut rather than Fn so an approver may keep state, such as remembering “always allow this file.” A plain function like ask_user fits the box too, because functions implement the Fn traits.

Calling it looks like the function pointer in part 1: (self.approve)(name, input), with parentheses so Rust doesn't look for a method named approve. Calling an FnMut needs mutable access, which is why execute_tool now takes &mut self.

Inside execute_tool, tool is borrowed from self.tools while we call self.approve mutably. That's fine, because Rust tracks borrows of different fields separately. But if you wrap the call in a helper method, fn ask(&mut self, ...), you'll get error[E0502]: cannot borrow `*self` as mutable because it is also borrowed as immutable. A method borrows all of self, not one field.

struct ToolDefinition {
    name: &'static str,
    description: &'static str,
    input_schema: Value,
    #[serde(skip)]
    function: fn(Value) -> Result<String, Box<dyn Error>>,
    #[serde(skip)]
    needs_approval: bool,
}

struct Agent<M: Model> {
    model: M,
    tools: Vec<ToolDefinition>,
    approve: Box<dyn FnMut(&str, &Value) -> bool>,
}

    fn new(
        model: M,
        tools: Vec<ToolDefinition>,
        approve: Box<dyn FnMut(&str, &Value) -> bool>,
    ) -> Agent<M> {
        Agent {
            model,
            tools,
            approve,
        }
    }

    fn execute_tool(&mut self, id: &str, name: &str, input: &Value) -> ContentBlock {
        let Some(tool) = self.tools.iter().find(|tool| tool.name == name) else {
            return ContentBlock::ToolResult {
                tool_use_id: id.to_string(),
                content: "tool not found".to_string(),
                is_error: true,
            };
        };

        if tool.needs_approval && !(self.approve)(name, input) {
            return ContentBlock::ToolResult {
                tool_use_id: id.to_string(),
                content: format!("the user did not allow this {name} call"),
                is_error: true,
            };
        }

        println!("\x1b[92mtool\x1b[0m: {name}({input})");
        let (content, is_error) = match (tool.function)(input.clone()) {
            Ok(output) => (output, false),
            Err(err) => (err.to_string(), true),
        };

        ContentBlock::ToolResult {
            tool_use_id: id.to_string(),
            content,
            is_error,
        }
    }

fn ask_user(name: &str, input: &Value) -> bool {
    print!("\x1b[95mAllow {name}({input})? [y/N]\x1b[0m ");
    if io::stdout().flush().is_err() {
        return false;
    }
    matches!(read_line(), Ok(Some(answer)) if answer.eq_ignore_ascii_case("y"))
}

2. A run log

The conversation is written for Claude. You need a different record, one written for you, of what the harness actually did. The conversation can't give you that. A denied edit and an edit that ran and failed both end up as an error tool_result, but one of them touched your disk and the other didn't. When something goes wrong, that's the first thing you'll want to know.

So the agent keeps a log of events, typed values that say what happened: the model was asked, a tool started, a tool finished, a call was refused, a limit was reached. Rejected calls are recorded as such, so “started” always means a tool really ran.

Specification

  • Add enum Event with the variants ModelRequested { round: usize }, ToolStarted { id: String, name: String }, ToolFinished { id: String, is_error: bool }, ToolRejected { id: String, name: String, reason: String }, and LimitReached { limit: Limit }. Add enum Limit with one variant, Rounds. It grows in chapter 4. Both derive Debug, Clone, PartialEq, and Limit is also Copy.
  • Agent gets log: Vec<Event>, which starts empty.
  • respond records ModelRequested { round } before every model call, with rounds counted from 1 within each turn, and LimitReached { limit: Limit::Rounds } when the round limit stops it.
  • execute_tool records ToolRejected with reason "unknown tool" or "denied by the user", or else ToolStarted just before the tool runs and ToolFinished just after.

Rust concept · a vocabulary of events

We could log strings like "tool started: read_file". An enum is better for three reasons. A typo in a variant name doesn't compile, while a typo in a string just silently breaks your search later. Each variant carries exactly the data that kind of event needs. And deriving PartialEq lets a test compare a whole log with assert_eq!, in one line.

Two small tools appear in the tests. agent.log.contains(&event) needs PartialEq too, and agent.log.last() returns an Option<&Event>, which is None for an empty log. 1..=MAX_TOOL_ROUNDS is an inclusive range, from 1 up to and including 10.

#[derive(Debug, Clone, PartialEq)]
enum Event {
    ModelRequested {
        round: usize,
    },
    ToolStarted {
        id: String,
        name: String,
    },
    ToolFinished {
        id: String,
        is_error: bool,
    },
    ToolRejected {
        id: String,
        name: String,
        reason: String,
    },
    LimitReached {
        limit: Limit,
    },
}

#[derive(Debug, Clone, Copy, PartialEq)]
enum Limit {
    Rounds,
}

struct Agent<M: Model> {
    model: M,
    tools: Vec<ToolDefinition>,
    approve: Box<dyn FnMut(&str, &Value) -> bool>,
    log: Vec<Event>,
}

    fn respond(&mut self, conversation: &mut Vec<Message>) -> Result<(), Box<dyn Error>> {
        for round in 1..=MAX_TOOL_ROUNDS {
            self.log.push(Event::ModelRequested { round });
            let content = self.model.complete(conversation, &self.tools)?;

            let mut tool_results = Vec::new();
            for block in &content {
                match block {
                    ContentBlock::Text { text } => println!("\x1b[93mClaude\x1b[0m: {text}"),
                    ContentBlock::ToolUse { id, name, input } => {
                        if already_answered(conversation, &tool_results, id) {
                            return Err(format!(
                                "Claude reused tool_use id {id}; refusing to run it twice"
                            )
                            .into());
                        }
                        tool_results.push(self.execute_tool(id, name, input));
                    }
                    ContentBlock::ToolResult { .. } => {}
                }
            }
            conversation.push(Message {
                role: Role::Assistant,
                content,
            });

            if tool_results.is_empty() {
                return Ok(());
            }
            conversation.push(Message {
                role: Role::User,
                content: tool_results,
            });
        }

        self.log.push(Event::LimitReached {
            limit: Limit::Rounds,
        });
        println!("\x1b[91mStopped after {MAX_TOOL_ROUNDS} rounds of tool calls.\x1b[0m");
        Ok(())
    }

    fn execute_tool(&mut self, id: &str, name: &str, input: &Value) -> ContentBlock {
        let Some(tool) = self.tools.iter().find(|tool| tool.name == name) else {
            self.log.push(Event::ToolRejected {
                id: id.to_string(),
                name: name.to_string(),
                reason: "unknown tool".to_string(),
            });
            return ContentBlock::ToolResult {
                tool_use_id: id.to_string(),
                content: "tool not found".to_string(),
                is_error: true,
            };
        };

        if tool.needs_approval && !(self.approve)(name, input) {
            self.log.push(Event::ToolRejected {
                id: id.to_string(),
                name: name.to_string(),
                reason: "denied by the user".to_string(),
            });
            return ContentBlock::ToolResult {
                tool_use_id: id.to_string(),
                content: format!("the user did not allow this {name} call"),
                is_error: true,
            };
        }

        println!("\x1b[92mtool\x1b[0m: {name}({input})");
        self.log.push(Event::ToolStarted {
            id: id.to_string(),
            name: name.to_string(),
        });
        let (content, is_error) = match (tool.function)(input.clone()) {
            Ok(output) => (output, false),
            Err(err) => (err.to_string(), true),
        };
        self.log.push(Event::ToolFinished {
            id: id.to_string(),
            is_error,
        });

        ContentBlock::ToolResult {
            tool_use_id: id.to_string(),
            content,
            is_error,
        }
    }

3. Save a session, replay without acting

When the program exits, the conversation and the log disappear. In this chapter we save them as a JSON file, and add a --replay mode that reads one back and shows what happened.

Replay has one hard rule: it never calls Claude and never runs a tool. A saved tool_use is a record of what happened, not an instruction to do it again. If replaying a session re-ran its edits, opening yesterday's log could change today's files. We'll make that impossible by design, not by being careful: replay takes only the saved session, so it has no model and no tools to call.

Loading a file also deserves suspicion. The file might be truncated, edited by hand, or written by a newer version of the program. serde checks that the JSON has the right shape. We then check that the history makes sense: every tool_use answered exactly once, and no ID used twice.

Specification

  • Derive Serialize, Deserialize, Clone, PartialEq on Role, Message and ContentBlock. Derive Serialize, Deserialize on Event, with #[serde(tag = "event", rename_all = "snake_case")], and on Limit, with #[serde(rename_all = "snake_case")].
  • Add struct Session { version: u32, conversation: Vec<Message>, log: Vec<Event> } with #[serde(deny_unknown_fields)], and the constants SESSION_VERSION = 1 and MAX_SESSION_BYTES = 1024 * 1024.
  • save_session(path: &Path, session: &Session) writes pretty JSON and refuses to overwrite an existing file.
  • load_session(path: &Path) -> Result<Session, ...> reads at most 1 MiB and rejects anything bigger, then parses the JSON and validates it.
  • validate_session rejects any version other than 1, a tool_use ID that appears twice, a tool_result that doesn't answer an earlier unanswered tool_use, and any tool_use left unanswered at the end.
  • replay(session: &Session) -> String renders one line per block: You: …, Claude: …, tool: name(input), and then -> ok, N bytes or -> error: ….
  • run returns the conversation when you press Ctrl-D. main then saves the session to sessions/session-<unix seconds>.json, and cargo run -- --replay <path> prints a saved session and exits.

Rust concept · files that refuse, bounded reads, and slice patterns

OpenOptions::new().write(true).create_new(true).open(path) asks the operating system to create the file only if it doesn't exist, in one step. Checking path.exists() first and then creating the file would leave a gap where another process could create it in between. File::open(path)?.take(MAX_SESSION_BYTES + 1) wraps the file in a reader that stops after that many bytes. We read one byte more than the limit so we can tell “exactly 1 MiB” from “more than 1 MiB.”

use std::fmt::Write as _; brings a trait into scope without giving it a name. We need its write_fmt method so writeln!(out, ...) works on a String, but the name Write is already taken by std::io::Write. Writing to a String can't fail, which is why .unwrap() is honest here.

if let [_, flag, path] = args.as_slice() && flag == "--replay" matches a slice against a pattern: exactly three elements, ignore the first, bind the other two. It's combined with a condition using a let chain, which needs edition 2024.

fn validate_session(session: &Session) -> Result<(), Box<dyn Error>> {
    if session.version != SESSION_VERSION {
        return Err(format!("unsupported session version {}", session.version).into());
    }

    let mut seen = HashSet::new();
    let mut unanswered: Vec<&str> = Vec::new();
    for message in &session.conversation {
        for block in &message.content {
            match block {
                ContentBlock::Text { .. } => {}
                ContentBlock::ToolUse { id, .. } => {
                    if !seen.insert(id.as_str()) {
                        return Err(format!("tool_use id {id} appears twice").into());

                }

                }
            }
        }
    }

        return Err(format!("tool_use {id} was never answered").into());

4. Spending limits

Every round sends the whole conversation again, so costs grow faster than you'd expect. If Claude reads a 5,000-token file and then takes six more rounds, those 5,000 tokens are paid for seven times. The ten-round limit from part 1 doesn't capture that: ten rounds of small requests are cheap, while ten rounds after reading a few large files are not.

So we add two more limits: a token budget for the whole session, counted from the usage the API reports, and a deadline for each turn. Like the round limit, they're checked between steps. A check can stop the next request, but it can't interrupt a request or a tool that's already running. And tokens are the closest thing to money we can count without knowing your prices. Check the pricing page for the model you use.

Specification

  • Response gets #[serde(default)] usage: Usage. struct Usage { input_tokens: u64, output_tokens: u64 } derives Default and is marked #[serde(default)], so missing numbers count as 0.
  • Model::complete returns the whole Response instead of just its content. The test fake's replies each report 100 input and 50 output tokens.
  • Replace MAX_TOOL_ROUNDS with struct Limits { max_rounds: usize, max_tokens: u64, deadline: Option<Duration> }, which defaults to 10 rounds, 500,000 tokens and 300 seconds. Agent gets limits: Limits (the default) and tokens_used: u64, counted across the whole session.
  • Before each model call, respond stops if tokens_used has reached max_tokens, or if the deadline has passed since this turn started. After each call, it adds the input and output tokens. A new stop(limit) method logs LimitReached and prints why, and Limit gains Tokens and Deadline.
  • Earlier tests that used MAX_TOOL_ROUNDS use Limits::default().max_rounds instead.

5. History that outgrows the window

A model can only read so much at once, its context window. A long enough session will eventually produce a request that's too big. The obvious fix, dropping the oldest messages, breaks things in two ways. A tool_result whose tool_use was dropped is invalid, and the API rejects it. And cutting into the middle of a turn keeps the answers but loses the question they answer.

So we follow three rules. Drop whole turns, oldest first. Always keep the latest turn, because that's the work in progress. And never edit the saved conversation: we only choose what to send. The full record stays intact for the log, the session file and replay.

A turn starts at a user message that contains no tool results, in other words a real question from you.

Specification

  • fn starts_a_turn(message: &Message) -> bool returns true for a user message with no ToolResult blocks.
  • fn select_context(conversation: &[Message], max_messages: usize) -> &[Message] returns the conversation from the earliest turn start whose remainder fits in max_messages. If even the latest turn doesn't fit, it returns the latest turn anyway. If there's no turn start at all, it returns everything.
  • Limits gets max_context_messages: usize, 200 by default, and respond sends select_context(...) instead of the whole conversation.
  • The fake model records every request it receives in requests: Vec<Vec<Message>>.

Counting messages is a stand-in. The real limit is measured in tokens, and one message can hold a huge file. Once this works, try trimming by tokens instead: the usage.input_tokens of the last response tells you how big the last request was.

6. Streaming, and replies that were cut off

Waiting for a whole reply feels slow, and streaming shows text as it's written. With "stream": true, the API sends server-sent events: lines like data: {"type":"content_block_delta", ...} that add to the reply piece by piece. Text arrives in fragments, and a tool call's input arrives as fragments of a JSON string.

That raises a new danger. A tool call must never run until the reply is complete. Halfway through, {"path": "src/ma is a different file from the one Claude meant. So the assembler shows text as it arrives but hands back nothing until it sees message_stop. A stream that ends early is an error, never a reply.

A complete reply can still be cut off. stop_reason: "max_tokens" means Claude ran out of room in the middle of writing, and a tool call at the end may have truncated input. We run nothing from such a reply, and we tell Claude to send the call again.

Specification

  • Response gets #[serde(default)] stop_reason: Option<String>.
  • If stop_reason is "max_tokens", respond runs none of the reply's tool calls. Each one gets an error result: {name} was not run: your response hit max_tokens, so its input may be incomplete. Send the call again with complete input. It's logged as ToolRejected with reason "the response was cut off".
  • Typed events: enum StreamEvent, internally tagged by "type", with an Unknown variant for event types we don't know, plus StreamStart, StreamStop and enum Delta.
  • fn assemble(lines: impl Iterator<Item = io::Result<String>>, on_text: &mut dyn FnMut(usize, &str)) -> Result<Response, ...>:
    • reads only lines starting with data:
    • builds blocks in index order and rejects anything out of order
    • appends text deltas and passes each one to on_text
    • collects tool input as a string and parses it at content_block_stop
    • takes usage from message_start and message_delta
    • returns only at message_stop, and only if every block was finished
  • Claude::complete sends "stream": true, reads the body line by line with BufReader::lines, and prints text as it arrives. respond no longer prints text itself.

Rust concept · a protocol as types

We could read each event as a loose serde_json::Value and pick fields out by name. Typed enums are safer. A misspelled field becomes a parse error instead of a silent null, and match forces us to decide what every event means. The API's versioning policy says new event types may appear, so #[serde(other)] Unknown catches any "type" we don't know instead of failing.

match (block, delta) matches two values at once. Because block is a &mut ContentBlock, the pattern ContentBlock::Text { text } binds text as a &mut String we can append to directly.

lines: impl Iterator<Item = io::Result<String>> accepts any iterator of lines. Claude passes lines read from the network, and the tests pass lines from a string. It's the same function with no fake needed. The printing closure in Claude::complete captures printing mutably to remember which block it's printing, which is exactly what FnMut allows.

fn assemble(
    lines: impl Iterator<Item = io::Result<String>>,
    on_text: &mut dyn FnMut(usize, &str),
) -> Result<Response, Box<dyn Error>> {
    let mut content: Vec<ContentBlock> = Vec::new();
    let mut tool_json: Vec<String> = Vec::new();
    let mut finished: Vec<bool> = Vec::new();
    let mut usage = Usage::default();
    let mut stop_reason = None;

    for line in lines {
        let line = line?;
        let Some(data) = line.strip_prefix("data: ") else {
            continue;
        };
        match serde_json::from_str(data)? {
            StreamEvent::MessageStart { message } => usage = message.usage,
            StreamEvent::ContentBlockStart {
                index,
                content_block,
            } => {
                if index != content.len() {
                    return Err(format!("content block {index} arrived out of order").into());
                }
                content.push(content_block);
                tool_json.push(String::new());
                finished.push(false);
            }
            StreamEvent::ContentBlockDelta { index, delta } => {
                let Some(block) = content.get_mut(index) else {
                    return Err(format!("a delta arrived for unknown block {index}").into());
                };
                match (block, delta) {
                    (ContentBlock::Text { text }, Delta::TextDelta { text: piece }) => {
                        on_text(index, &piece);
                        text.push_str(&piece);
                    }
                    (ContentBlock::ToolUse { .. }, Delta::InputJsonDelta { partial_json }) => {
                        tool_json[index].push_str(&partial_json);
                    }
                    (_, Delta::Unknown) => {}
                    _ => return Err(format!("a delta doesn't match block {index}").into()),
                }
            }
            StreamEvent::ContentBlockStop { index } => {
                if let Some(ContentBlock::ToolUse { input, .. }) = content.get_mut(index)
                    && !tool_json[index].is_empty()
                {
                    *input = serde_json::from_str(&tool_json[index])?;
                }
                if let Some(done) = finished.get_mut(index) {
                    *done = true;
                }
            }
            StreamEvent::MessageDelta {
                delta,
                usage: total,
            } => {
                stop_reason = delta.stop_reason;
                usage.output_tokens = total.output_tokens;
                if total.input_tokens > 0 {
                    usage.input_tokens = total.input_tokens;
                }
            }
            StreamEvent::MessageStop => {
                if finished.contains(&false) {
                    return Err("message_stop arrived before every block was finished".into());
                }
                return Ok(Response {
                    content,
                    usage,
                    stop_reason,
                });
            }
            StreamEvent::Error { error } => {
                return Err(format!("the API sent an error: {error}").into());
            }
            StreamEvent::Ping | StreamEvent::Unknown => {}
        }
    }
    Err("the stream ended before message_stop, so the reply is incomplete".into())
}

                return Ok(());

                && started.elapsed() >= deadline
            {
                self.stop(Limit::Deadline);
                return Ok(());

            let request = select_context(conversation, self.limits.max_context_messages);
            let response = self.model.complete(request, &self.tools)?;
            self.tokens_used += response.usage.input_tokens + response.usage.output_tokens;

            let content = response.content;

            let mut tool_results = Vec::new();
            for block in &content {
                match block {
                    ContentBlock::Text { .. } => {}
                    ContentBlock::ToolUse { id, name, input } => {
                        if already_answered(conversation, &tool_results, id) {
                            return Err(format!(

                            )
                            .into());
                        }

                            self.log.push(Event::ToolRejected {
                                id: id.clone(),
                                name: name.clone(),
                                reason: "the response was cut off".to_string(),
                            });
                            tool_results.push(ContentBlock::ToolResult {
                                tool_use_id: id.clone(),
                                content: format!(
                                    "{name} was not run: your response hit max_tokens, so its input may be incomplete. Send the call again with complete input."
                                ),
                                is_error: true,
                            });
                            continue;
                        }
                        tool_results.push(self.execute_tool(id, name, input));
                    }
                    ContentBlock::ToolResult { .. } => {}
                }
            }
            conversation.push(Message {
                role: Role::Assistant,
                content,
            });

            if tool_results.is_empty() {
                return Ok(());
            }
            conversation.push(Message {
                role: Role::User,
                content: tool_results,
            });
        }

        self.stop(Limit::Rounds);
        Ok(())
    }

7. Thinking models

Newer models such as claude-sonnet-5-5 think before they answer, and the API returns that thinking as thinking content blocks. By default their text is empty, and a signature field carries the reasoning in encrypted form. Our agent can't read these blocks yet: the first one fails with unknown variant `thinking`.

The thinking docs set two rules that matter for a harness:

  • Pass thinking blocks back unchanged, including redacted_thinking blocks, in later requests during tool use. So our types must not drop any field, including fields added in the future.
  • Don't change the history before a thinking block. On Claude Sonnet 5.5, the API checks that nothing before a thinking block has changed since it was produced, and on newer accounts a changed history is rejected. Chapter 5's trimming changes the history. A request without thinking blocks has nothing to check, and the docs suggest exactly that remedy: strip the thinking blocks from the edited point onward. So when we trim, we send the request without any thinking blocks. The saved conversation keeps them.

Specification

  • ContentBlock gets Thinking { thinking: String, signature: String, extra } and RedactedThinking { data: String, extra }, where extra is a #[serde(flatten)] Map<String, Value> that keeps any other fields.
  • Every match on ContentBlock handles them. The compiler will list each one: respond, validate_session and replay, which prints Claude: (thinking).
  • Delta gets ThinkingDelta { thinking } and SignatureDelta { signature }, and assemble appends them to the thinking block.
  • fn without_thinking(messages: &[Message]) -> Vec<Message> copies the messages without thinking blocks. If select_context dropped anything, respond sends that copy instead.
  • Set MODEL to "claude-sonnet-5-5" and max_tokens to 16000, because thinking uses part of the output budget.

One behavior to expect: on this model, the longer notes Claude writes between tool calls come back as thinking blocks, so the agent is quieter between tool calls than it was with Haiku.

What you've built

Your agent still has the same small loop from part 1. Around it, the harness now decides what may run (validation, approval, cut-off replies), how much may happen (rounds, tokens, time), what the model sees (whole turns, with thinking blocks intact or stripped), and what you can check afterward (a typed log and sessions you can replay). The model proposes, and the harness decides. None of those decisions depends on what the model says.

Where to go next

  • Run commands, safely. A run_command tool is where checked_path stops being enough. A command can touch anything your user account can. Real isolation comes from the operating system: a container, a separate user, or a sandbox with no network. Ask for approval every time, and test what happens when it's denied.
  • Do things in parallel. When Claude asks for several reads at once, they could run concurrently. That's the point where async Rust and a runtime such as Tokio start to pay off. Async doesn't replace any of the checks you've built. See §17 Async and await.
  • Connect more tools. The Model Context Protocol is a standard way to connect tools written by others. It changes where tools come from, not the loop. Approval, limits and logging still belong to your harness.
  • Split it up. At over 1,000 lines, including tests, it's time for modules: model.rs, tools.rs, session.rs, stream.rs. See §7.5 Separating modules into different files.

impl<M: Model> Agent<M> {
    fn new(
        model: M,
        tools: Vec<ToolDefinition>,
        approve: Box<dyn FnMut(&str, &Value) -> bool>,
    ) -> Agent<M> {
        Agent {
            model,
            tools,
            approve,
            log: Vec::new(),
            limits: Limits::default(),
            tokens_used: 0,
        }
    }

    fn run(&mut self) -> Result<Vec<Message>, Box<dyn Error>> {
        let mut conversation: Vec<Message> = Vec::new();

        println!("Chat with Claude (use 'ctrl-c' to quit)");

        loop {
            print!("\x1b[94mYou\x1b[0m: ");
            io::stdout().flush()?;
            let Some(user_input) = read_line()? else {
                break;
            };
            if user_input.is_empty() {
                continue;
            }
            conversation.push(Message {
                role: Role::User,
                content: vec![ContentBlock::Text { text: user_input }],
            });

            self.respond(&mut conversation)?;
        }

        Ok(conversation)
    }

    fn respond(&mut self, conversation: &mut Vec<Message>) -> Result<(), Box<dyn Error>> {
        let started = Instant::now();
        for round in 1..=self.limits.max_rounds {
            if self.tokens_used >= self.limits.max_tokens {
                self.stop(Limit::Tokens);
                return Ok(());
            }
            if let Some(deadline) = self.limits.deadline
                && started.elapsed() >= deadline
            {
                self.stop(Limit::Deadline);
                return Ok(());
            }

            self.log.push(Event::ModelRequested { round });
            let selected = select_context(conversation, self.limits.max_context_messages);
            let stripped;
            let request: &[Message] = if selected.len() < conversation.len() {
                stripped = without_thinking(selected);
                &stripped
            } else {
                selected
            };
            let response = self.model.complete(request, &self.tools)?;
            self.tokens_used += response.usage.input_tokens + response.usage.output_tokens;
            let truncated = response.stop_reason.as_deref() == Some("max_tokens");
            let content = response.content;

            let mut tool_results = Vec::new();
            for block in &content {
                match block {
                    ContentBlock::Text { .. } => {}
                    ContentBlock::ToolUse { id, name, input } => {
                        if already_answered(conversation, &tool_results, id) {
                            return Err(format!(
                                "Claude reused tool_use id {id}; refusing to run it twice"
                            )
                            .into());
                        }
                        if truncated {
                            self.log.push(Event::ToolRejected {
                                id: id.clone(),
                                name: name.clone(),
                                reason: "the response was cut off".to_string(),
                            });
                            tool_results.push(ContentBlock::ToolResult {
                                tool_use_id: id.clone(),
                                content: format!(
                                    "{name} was not run: your response hit max_tokens, so its input may be incomplete. Send the call again with complete input."
                                ),
                                is_error: true,
                            });
                            continue;
                        }
                        tool_results.push(self.execute_tool(id, name, input));
                    }
                    ContentBlock::ToolResult { .. }
                    | ContentBlock::Thinking { .. }
                    | ContentBlock::RedactedThinking { .. } => {}
                }
            }
            conversation.push(Message {
                role: Role::Assistant,
                content,
            });

            if tool_results.is_empty() {
                return Ok(());
            }
            conversation.push(Message {
                role: Role::User,
                content: tool_results,
            });
        }

        self.stop(Limit::Rounds);
        Ok(())
    }

    fn stop(&mut self, limit: Limit) {
        self.log.push(Event::LimitReached { limit });
        let reason = match limit {
            Limit::Rounds => format!("{} rounds of tool calls", self.limits.max_rounds),
            Limit::Tokens => format!("the budget of {} tokens", self.limits.max_tokens),
            Limit::Deadline => "the time limit for one turn".to_string(),
        };
        println!("\x1b[91mStopped: reached {reason}.\x1b[0m");
    }

    fn execute_tool(&mut self, id: &str, name: &str, input: &Value) -> ContentBlock {
        let Some(tool) = self.tools.iter().find(|tool| tool.name == name) else {
            self.log.push(Event::ToolRejected {
                id: id.to_string(),
                name: name.to_string(),
                reason: "unknown tool".to_string(),
            });
            return ContentBlock::ToolResult {
                tool_use_id: id.to_string(),
                content: "tool not found".to_string(),
                is_error: true,
            };
        };

        if tool.needs_approval && !(self.approve)(name, input) {
            self.log.push(Event::ToolRejected {
                id: id.to_string(),
                name: name.to_string(),
                reason: "denied by the user".to_string(),
            });
            return ContentBlock::ToolResult {
                tool_use_id: id.to_string(),
                content: format!("the user did not allow this {name} call"),
                is_error: true,
            };
        }

        println!("\x1b[92mtool\x1b[0m: {name}({input})");
        self.log.push(Event::ToolStarted {
            id: id.to_string(),
            name: name.to_string(),
        });
        let (content, is_error) = match (tool.function)(input.clone()) {
            Ok(output) => (output, false),
            Err(err) => (err.to_string(), true),
        };
        self.log.push(Event::ToolFinished {
            id: id.to_string(),
            is_error,
        });

        ContentBlock::ToolResult {
            tool_use_id: id.to_string(),
            content,
            is_error,
        }
    }
}

fn select_context(conversation: &[Message], max_messages: usize) -> &[Message] {
    let Some(latest) = conversation.iter().rposition(starts_a_turn) else {
        return conversation;
    };
    let start = (0..=latest)
        .find(|&i| starts_a_turn(&conversation[i]) && conversation.len() - i <= max_messages)
        .unwrap_or(latest);
    &conversation[start..]
}

fn without_thinking(messages: &[Message]) -> Vec<Message> {
    messages
        .iter()
        .map(|message| Message {
            role: message.role.clone(),
            content: message
                .content
                .iter()
                .filter(|block| {
                    !matches!(
                        block,
                        ContentBlock::Thinking { .. } | ContentBlock::RedactedThinking { .. }
                    )
                })
                .cloned()
                .collect(),
        })
        .filter(|message| !message.content.is_empty())
        .collect()
}

fn starts_a_turn(message: &Message) -> bool {
    message.role == Role::User
        && !message
            .content
            .iter()
            .any(|block| matches!(block, ContentBlock::ToolResult { .. }))
}

fn already_answered(conversation: &[Message], pending: &[ContentBlock], id: &str) -> bool {
    conversation
        .iter()
        .flat_map(|message| &message.content)
        .chain(pending)
        .any(|block| matches!(block, ContentBlock::ToolResult { tool_use_id, .. } if tool_use_id == id))
}

fn load_session(path: &Path) -> Result<Session, Box<dyn Error>> {
    let mut text = String::new();
    File::open(path)?
        .take(MAX_SESSION_BYTES + 1)
        .read_to_string(&mut text)?;
    if text.len() as u64 > MAX_SESSION_BYTES {
        return Err("the session file is larger than 1 MiB".into());
    }
    let session: Session = serde_json::from_str(&text)?;
    validate_session(&session)?;
    Ok(session)
}

fn validate_session(session: &Session) -> Result<(), Box<dyn Error>> {
    if session.version != SESSION_VERSION {
        return Err(format!("unsupported session version {}", session.version).into());
    }

    let mut seen = HashSet::new();
    let mut unanswered: Vec<&str> = Vec::new();
    for message in &session.conversation {
        for block in &message.content {
            match block {
                ContentBlock::Text { .. }
                | ContentBlock::Thinking { .. }
                | ContentBlock::RedactedThinking { .. } => {}
                ContentBlock::ToolUse { id, .. } => {
                    if !seen.insert(id.as_str()) {
                        return Err(format!("tool_use id {id} appears twice").into());
                    }
                    unanswered.push(id);
                }
                ContentBlock::ToolResult { tool_use_id, .. } => {
                    let Some(index) = unanswered.iter().position(|id| id == tool_use_id) else {
                        return Err(format!(
                            "tool_result {tool_use_id} answers no earlier tool_use"
                        )
                        .into());
                    };
                    unanswered.remove(index);
                }
            }
        }
    }
    if let Some(id) = unanswered.first() {
        return Err(format!("tool_use {id} was never answered").into());
    }
    Ok(())
}

fn replay(session: &Session) -> String {
    let mut out = String::new();
    for message in &session.conversation {
        for block in &message.content {
            match (&message.role, block) {
                (Role::User, ContentBlock::Text { text }) => writeln!(out, "You: {text}").unwrap(),
                (Role::Assistant, ContentBlock::Text { text }) => {
                    writeln!(out, "Claude: {text}").unwrap()
                }
                (_, ContentBlock::ToolUse { name, input, .. }) => {
                    writeln!(out, "tool: {name}({input})").unwrap()
                }
                (
                    _,
                    ContentBlock::ToolResult {
                        content, is_error, ..
                    },
                ) => {
                    if *is_error {
                        writeln!(out, "  -> error: {content}").unwrap()
                    } else {
                        writeln!(out, "  -> ok, {} bytes", content.len()).unwrap()
                    }
                }
                (_, ContentBlock::Thinking { .. } | ContentBlock::RedactedThinking { .. }) => {
                    writeln!(out, "Claude: (thinking)").unwrap()
                }
            }
        }
    }
    out
}

fn assemble(
    lines: impl Iterator<Item = io::Result<String>>,
    on_text: &mut dyn FnMut(usize, &str),
) -> Result<Response, Box<dyn Error>> {
    let mut content: Vec<ContentBlock> = Vec::new();
    let mut tool_json: Vec<String> = Vec::new();
    let mut finished: Vec<bool> = Vec::new();
    let mut usage = Usage::default();
    let mut stop_reason = None;

    for line in lines {
        let line = line?;
        let Some(data) = line.strip_prefix("data: ") else {
            continue;
        };
        match serde_json::from_str(data)? {
            StreamEvent::MessageStart { message } => usage = message.usage,
            StreamEvent::ContentBlockStart {
                index,
                content_block,
            } => {
                if index != content.len() {
                    return Err(format!("content block {index} arrived out of order").into());
                }
                content.push(content_block);
                tool_json.push(String::new());
                finished.push(false);
            }
            StreamEvent::ContentBlockDelta { index, delta } => {
                let Some(block) = content.get_mut(index) else {
                    return Err(format!("a delta arrived for unknown block {index}").into());
                };
                match (block, delta) {
                    (ContentBlock::Text { text }, Delta::TextDelta { text: piece }) => {
                        on_text(index, &piece);
                        text.push_str(&piece);
                    }
                    (ContentBlock::ToolUse { .. }, Delta::InputJsonDelta { partial_json }) => {
                        tool_json[index].push_str(&partial_json);
                    }
                    (
                        ContentBlock::Thinking { thinking, .. },
                        Delta::ThinkingDelta { thinking: piece },
                    ) => {
                        thinking.push_str(&piece);
                    }
                    (
                        ContentBlock::Thinking { signature, .. },
                        Delta::SignatureDelta { signature: piece },
                    ) => {
                        signature.push_str(&piece);
                    }
                    (_, Delta::Unknown) => {}
                    _ => return Err(format!("a delta doesn't match block {index}").into()),
                }
            }
            StreamEvent::ContentBlockStop { index } => {
                if let Some(ContentBlock::ToolUse { input, .. }) = content.get_mut(index)
                    && !tool_json[index].is_empty()
                {
                    *input = serde_json::from_str(&tool_json[index])?;
                }
                if let Some(done) = finished.get_mut(index) {
                    *done = true;
                }
            }
            StreamEvent::MessageDelta {
                delta,
                usage: total,
            } => {
                stop_reason = delta.stop_reason;
                usage.output_tokens = total.output_tokens;
                if total.input_tokens > 0 {
                    usage.input_tokens = total.input_tokens;
                }
            }
            StreamEvent::MessageStop => {
                if finished.contains(&false) {
                    return Err("message_stop arrived before every block was finished".into());
                }
                return Ok(Response {
                    content,
                    usage,
                    stop_reason,
                });
            }
            StreamEvent::Error { error } => {
                return Err(format!("the API sent an error: {error}").into());
            }
            StreamEvent::Ping | StreamEvent::Unknown => {}
        }
    }
    Err("the stream ended before message_stop, so the reply is incomplete".into())
}

#[derive(Serialize)]
struct ToolDefinition {
    name: &'static str,
    description: &'static str,
    input_schema: Value,
    #[serde(skip)]
    function: fn(Value) -> Result<String, Box<dyn Error>>,
    #[serde(skip)]
    needs_approval: bool,
}

fn checked_path(path: &str) -> Result<&Path, Box<dyn Error>> {
    let path = Path::new(path);
    for component in path.components() {
        match component {
            Component::Normal(_) | Component::CurDir => {}
            _ => {
                return Err(format!(
                    "{} is outside the working directory; use a relative path without '..'",
                    path.display()
                )
                .into());
            }
        }
    }
    Ok(path)
}

#[derive(Deserialize)]
struct ReadFileInput {
    path: String,
}

fn read_file_tool() -> ToolDefinition {
    ToolDefinition {
        name: "read_file",
        description: "Read the contents of a given relative file path. Use this when you want to see what's inside a file. Do not use this with directory names.",
        input_schema: json!({
            "type": "object",
            "properties": {
                "path": {
                    "type": "string",
                    "description": "The relative path of a file in the working directory."
                }
            },
            "required": ["path"]
        }),
        function: read_file,
        needs_approval: false,
    }
}

fn read_file(input: Value) -> Result<String, Box<dyn Error>> {
    let input: ReadFileInput = serde_json::from_value(input)?;
    let content = fs::read_to_string(checked_path(&input.path)?)?;
    Ok(content)
}

#[derive(Deserialize)]
struct ListFilesInput {
    path: Option<String>,
}

fn list_files_tool() -> ToolDefinition {
    ToolDefinition {
        name: "list_files",
        description: "List files and directories at a given path. If no path is provided, lists files in the current directory.",
        input_schema: json!({
            "type": "object",
            "properties": {
                "path": {
                    "type": "string",
                    "description": "Optional relative path to list files from. Defaults to current directory if not provided."
                }
            }
        }),
        function: list_files,
        needs_approval: false,
    }
}

fn list_files(input: Value) -> Result<String, Box<dyn Error>> {
    let input: ListFilesInput = serde_json::from_value(input)?;
    let dir = match input.path {
        Some(path) if !path.is_empty() => path,
        _ => ".".to_string(),
    };
    let dir = checked_path(&dir)?;

    let mut files = Vec::new();
    walk(dir, dir, &mut files)?;
    files.sort();

    Ok(serde_json::to_string(&files)?)
}

fn walk(root: &Path, dir: &Path, files: &mut Vec<String>) -> io::Result<()> {
    for entry in fs::read_dir(dir)? {
        let path = entry?.path();
        if path.ends_with(".git") || path.ends_with("target") {
            continue;
        }

        let relative = path
            .strip_prefix(root)
            .unwrap_or(&path)
            .display()
            .to_string();
        if path.is_dir() {
            files.push(format!("{relative}/"));
            walk(root, &path, files)?;
        } else {
            files.push(relative);
        }
    }
    Ok(())
}

#[derive(Deserialize)]
struct EditFileInput {
    path: String,
    old_str: String,
    new_str: String,
}

fn edit_file_tool() -> ToolDefinition {
    ToolDefinition {
        name: "edit_file",
        description: "Make edits to a text file.

Replaces 'old_str' with 'new_str' in the given file. 'old_str' and 'new_str' MUST be different from each other. 'old_str' must match exactly one place in the file.

If the file specified with path doesn't exist, it will be created when 'old_str' is empty.",
        input_schema: json!({
            "type": "object",
            "properties": {
                "path": {
                    "type": "string",
                    "description": "The path to the file"
                },
                "old_str": {
                    "type": "string",
                    "description": "Text to search for - must match exactly and must only have one match exactly"
                },
                "new_str": {
                    "type": "string",
                    "description": "Text to replace old_str with"
                }
            },
            "required": ["path", "old_str", "new_str"]
        }),
        function: edit_file,
        needs_approval: true,
    }
}

fn edit_file(input: Value) -> Result<String, Box<dyn Error>> {
    let input: EditFileInput = serde_json::from_value(input)?;
    if input.path.is_empty() || input.old_str == input.new_str {
        return Err("invalid input parameters".into());
    }
    let path = checked_path(&input.path)?;

    let content = match fs::read_to_string(path) {
        Ok(content) => content,
        Err(err) if err.kind() == io::ErrorKind::NotFound && input.old_str.is_empty() => {
            return create_new_file(path, &input.new_str);
        }
        Err(err) => return Err(err.into()),
    };

    if input.old_str.is_empty() {
        return Err("the file already exists, so old_str must not be empty".into());
    }

    match content.matches(&input.old_str).count() {
        0 => Err("old_str not found in file".into()),
        1 => {
            fs::write(path, content.replacen(&input.old_str, &input.new_str, 1))?;
            Ok("OK".to_string())
        }
        n => Err(format!("old_str found {n} times, it must match exactly once").into()),
    }
}

fn create_new_file(path: &Path, content: &str) -> Result<String, Box<dyn Error>> {
    if let Some(dir) = path.parent() {
        fs::create_dir_all(dir)?;
    }
    fs::write(path, content)?;
    Ok(format!("Successfully created file {}", path.display()))
}

            tool_use(
                id,
                "edit_file",
                json!({"path": path, "old_str": "old", "new_str": "new"}),
            )
        };

            ],
            Box::new(move |_, input| input["path"] == a),
        );
        let mut conversation = ask("Change old to new in both files.");

        let claim = &conversation[3].content[0];
        assert_eq!(claim, &text("Done! I updated both files."));

        assert_eq!(fs::read_to_string(a).unwrap(), "new");
        assert_eq!(fs::read_to_string(b).unwrap(), "old");

        let succeeded = agent
            .log
            .iter()
            .filter(|event| {
                matches!(
                    event,
                    Event::ToolFinished {
                        is_error: false,
                        ..
                    }
                )
            })
            .count();
        assert_eq!(succeeded, 1);
        assert!(agent.log.iter().any(|event| matches!(
            event,
            Event::ToolRejected { id, .. } if id == "t2"
        )));
        assert_eq!(agent.tokens_used, 300);

        let session = Session {
            version: SESSION_VERSION,
            conversation,
            log: agent.log,
        };

        let loaded = load_session(session_path).unwrap();
